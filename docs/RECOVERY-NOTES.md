## How to get closer to the original

1. **`@Metadata` annotations** — every class retains Kotlin signatures and the original source file name. A Kotlin decompiler (IntelliJ plugin / `kotlin-decompiler`) can recover `.kt` more faithfully than jadx.
2. **Rebuild Gradle** — read `META-INF/*.version` in the APK for the exact dependency versions. The included skeleton is only indicative.
3. **Clean filler imports** — remove/replace `ConstraintLayout`, `NotificationCompat`, etc., used only as constants inside annotations.
4. **R.java** — generated by the Android Gradle Plugin from `res/`; it should not be committed.
5. **Data Binding** — `databinding/*` is generated from layouts and will be regenerated when rebuilding.
